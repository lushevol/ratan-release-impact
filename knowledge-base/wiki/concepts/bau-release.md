# BAU Release

A **BAU release** is a release or change described as part of business-as-usual operational delivery rather than explicitly identified as a major project rollout.

In this source, the term appears in the filename label for [[chg1004769]]: **Ratan BAU Release - Manual Entity UVT**. The available source metadata does not establish the release cadence, approval status, implementation outcome, or detailed scope.

BAU classification should not be used to infer that a change is monthly. Any relationship to [[monthly-release]] requires explicit evidence from the release record or governing documentation.

The release-governance context is associated with [[pre-cab-release-governance]] and [[release-management]].
