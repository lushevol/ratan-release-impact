# Adhoc Suppression Maker-Checker Workflow

The Adhoc Suppression Maker-Checker workflow is a secondary workflow shown in the technical-design proposal alongside the NSTP maker-checker workflow.

Its inclusion indicates that the proposed Camunda-based process-domain approach is intended to apply beyond NSTP. However, the source provides only a referenced diagram and no extractable details about triggers, approval rules, persistence, status transitions, exception handling, or implementation scope.

It should therefore be treated as proposed related scope, not as a defined or implemented workflow contract.
