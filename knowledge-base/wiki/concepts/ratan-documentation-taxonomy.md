# RATAN Documentation Taxonomy

The RATAN Confluence index divides knowledge into named documentation areas. It is an information-architecture signal rather than evidence of documented implementation or approved operational practice.

## Listed Domains

The index names these domains:

- Application overview and application documentation
- Architecture
- Capacity
- Core function
- Infrastructure
- Interfaces
- OLA
- KTLO tracking
- Knowledge base
- Monitoring
- Projects
- Release
- SME
- Security
- Service restart guidance

## Use in This Wiki

Existing implementation-oriented material can be tentatively navigated through these domains without asserting that it corresponds to, replaces, or is endorsed by the linked Confluence pages.

Examples include:

- Architecture and application documentation: [[ratanone-ui-performance]]
- Infrastructure, capacity, and monitoring: [[redis-client-outage-recovery]] and [[cash-settlement-database-retention-and-housekeeping]]
- Core function: [[ratan-cashflow-lifecycle-service]]
- Interfaces: [[rdm]], [[enisis]], [[tlm]], and [[solace]]

## Limitations

The taxonomy provides neither scope definitions nor ownership boundaries. In particular, it does not define relationships among App Docs, Architecture, Core Function, and Interfaces, or among OLA, KTLO Tracker, Monitoring, Capacity, and Service Restart Guide.

It also does not demonstrate that any linked page is current, complete, accessible, or authoritative.
