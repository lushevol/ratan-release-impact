# EBBS Posting Configuration

EBBS posting configuration combines an entity's bridge account with posting branch, transaction type, debit transaction code, and credit transaction code used for accounting.

The Tranche 2 checklist supplies values for Bahrain, Qatar, Uganda, Ghana, and Nigeria. It also records that Qatar requires double confirmation, so its listed bridge-account data remains unverified.

A note changing Tanzania's credit transaction code from `278` to `578` is outside the five-country Tranche 2 scope and must not be generalized to Bahrain, Qatar, Uganda, Ghana, or Nigeria.
