# Payment versus Payment

Payment versus Payment, or PvP, is a settlement mechanism intended to coordinate payment obligations so that one payment occurs in connection with the other.

## Backlog Scope

The 2025 FMRP backlog lists “New Feature: CHATS / PvP” in the Day 2 portfolio. It provides no priority, ADO identifier, entity scope, implementation approach, schedule, or acceptance criteria for this item.

The backlog separately defines a phased [[delivery-versus-payment]] proposal. DVP and PvP should be treated as distinct settlement concepts even though both appear in the same Day 2 feature portfolio.
