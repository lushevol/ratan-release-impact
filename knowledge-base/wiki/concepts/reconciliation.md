# Reconciliation

Reconciliation compares records between systems or processing stages to identify missing, duplicated, or inconsistent transactions.

## TLM Integration

In [[chg1016055]], [[51358-ratan-cash-settlement-accounting-service]] integrates a tactical TLM reconciliation API.

A performance-test record states that the API response contained 20,286 items. This establishes test volume but does not establish acceptable performance because response-time, throughput, error-rate, concurrency, duration, and threshold data are not transcribed.
