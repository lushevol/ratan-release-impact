# EBBS Settlement Posting Configuration

EBBS settlement posting configuration comprises an entity-level bridge account plus FMID-level posting branch, transaction type, debit transaction code, and credit transaction code.

The checklist assigns transaction type `RTN` to all listed records. It records a Tanzania credit-code change from `278` to `578` on 2026-06-15.

Qatar and Bangladesh bridge-account values were supplied but explicitly require double confirmation. The source does not show confirmation or deployment.
