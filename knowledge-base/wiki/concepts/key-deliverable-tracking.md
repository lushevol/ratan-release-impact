# Key-Deliverable Tracking

## Definition

Key-deliverable tracking is a named RATAN delivery-management reference category. The SME index links to **Ratan Tracking of List of key deliverables**.

The source does not list the deliverables or provide milestones, deadlines, owners, dependencies, completion states, risks, or escalation criteria.

## Evidence boundary

This source supports only the existence of a reference point for tracking key deliverables. It does not support a conclusion about delivery progress or identify any deliverable as at risk. The linked Confluence page should be reviewed before documenting RATAN delivery commitments or governance.
