# Netting-Set Affirmation

Netting-set validation requires an affirmation email. Clients must be able to set notification preferences.

[[cadm]] is proposed as the client-data source, but its role is marked TBC. The source does not define delivery channels, email templates, recipient selection, acknowledgement behavior, or failure handling.
