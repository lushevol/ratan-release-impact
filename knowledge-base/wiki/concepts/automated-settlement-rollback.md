# Automated Settlement Rollback

Automated settlement rollback is an operational control intended to reverse or safely recover from an unsuccessful or unsafe settlement-processing change. The source lists an automated rollback solution for the UK as a must-have, at-risk feature.

The tracker does not state whether the solution was delivered, which events trigger rollback, how already-published cashflows are handled, or who authorizes recovery. It should therefore be treated as planned scope rather than confirmed production capability.
