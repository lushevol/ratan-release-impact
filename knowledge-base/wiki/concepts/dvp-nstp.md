# DVP NSTP

DVP NSTP is a delivery-versus-payment processing requirement involving non-straight-through processing behavior.

The utilization-pilot scope marks DVP NSTP as included and assigns a dependency to Stella/TDSX payment-schedule data. The source adds the unresolved qualifier “only for CN booking?” This qualifier prevents the requirement from being treated as definitively CN-only or universally applicable.

DVP NSTP should be analyzed separately from the Murex 2.11 dependencies for lien, clearing, and suppression indicators.
