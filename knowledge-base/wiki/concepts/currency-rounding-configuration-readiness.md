# Currency Rounding Configuration Readiness

Currency rounding configuration readiness is the onboarding check that confirms a newly introduced currency is available in RATAN's current rounding configuration.

The cited configuration is tactical rounding logic associated with the H1 cashflow-migration release for SG/MY/IN. The source requires the availability check but does not specify rounding scales, calculation method, product scope, fallback behavior, or whether this tactical configuration remains authoritative for later BAU currencies.

This differs from [[manual-cashflow-rounding]] and [[manual-rounding-amendment]], which address cashflow amendment behavior rather than onboarding configuration coverage.
