# Murex EOD Proxy

A Murex EOD proxy is the migration-related role attributed to [[ratan]]'s EOD capability. The source states that it is used to accelerate [[murex-g2000]] EOD migration under [[strategic-fm-re-platforming-sfmrp]].

RATAN's EOD capability is built as a tenant on [[fm-data-platform]] and is also used for risk/valuations feed adoption for Operations systems.

The current evidence does not define whether the proxy is feed-only, which Murex EOD functions it represents, its data ownership and reconciliation model, its intended lifetime, or its retirement criteria. These questions remain tracked in [[what-functions-does-the-ratan-murex-g2000-eod-proxy-perform]].
