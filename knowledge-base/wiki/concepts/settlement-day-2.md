# Settlement Day 2

## Definition and scope

Settlement Day 2 is a requirement grouping identified in the source path.

In the **Auto Netting Static Go Live Process** source, Settlement Day 2 is used as an operational requirement grouping for staged cash-settlement and auto-netting static-data changes. The associated process includes:

- Rule creation
- Rule updates
- Suppression configuration
- NSTP assignment
- Migration of selected manual netting rules

The available evidence does not establish whether Settlement Day 2 represents a delivery phase, an operational settlement day, a release milestone, or another classification in all contexts.
