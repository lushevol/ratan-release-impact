# Strategic Cash Settlement Entitlement Model

The RATANONE technical design states that Strategic Cash Settlement uses one EMS2 entity, [[x-ratanone]], while different tiles are controlled through different subjects.

This differs from the documented BCS/EG model, where different tiles use different EMS2 entities during a transition to CN.

The document does not define subjects, claims, roles, administrative ownership, segregation of duties, or enforcement controls. The current configuration should not be inferred from this architecture inventory alone.
