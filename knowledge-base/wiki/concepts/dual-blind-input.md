# Dual Blind Input

Dual Blind Input is an independent dual-entry control for settlement-instruction or payment input. The source lists it as a RATAN capability intended to reduce input risk.

## Operational trade-off

The source presents Dual Blind Input as a risk-reduction measure but also states that it increases checker processing time. It should therefore be assessed as a control with both benefits and operational cost, rather than as an unqualified efficiency improvement.

The source does not define the exact input fields, matching rules, exception behaviour, or approval workflow.
