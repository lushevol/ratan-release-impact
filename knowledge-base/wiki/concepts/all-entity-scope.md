# All-Entity Scope

All-entity scope describes a deployment or onboarding population intended to cover every applicable entity within a defined business or processing boundary.

For [[chg1003770]], `All Entity` is a filename-level scope qualifier. The source does not define the entity population, legal-entity boundary, applicability rules, acceptance criteria, or exclusions. It must therefore be treated as an unresolved scope label rather than as proof that every RATAN entity was included.

## Scope confirmation

The authoritative change documentation should identify the entities covered, any exceptions or phased exclusions, environment and deployment boundaries, readiness criteria, and evidence that each applicable entity completed onboarding.
