# 2025 Tranche 2 Onboarding Readiness

Readiness requires more than assigning configuration owners. It depends on verified application configuration, static data, downstream analysis, access, user acceptance testing, and regression testing.

For this checklist, firewall access is explicitly marked `Done`, but UAT and regression testing are marked `No`. The NDS Auto Netting and Pending Fixing STP/NSTP blacklists are `TBD`, and the source does not provide a complete status for most other rows. Consequently, the checklist alone does not demonstrate go-live readiness.

Completion evidence should identify the configured entity and branch identifiers, implementation owner, test evidence, approval status, and any remaining exceptions.
