# Manual-Entity Go-Live Static-Data Controls

Manual-entity settlement onboarding requires aligned configuration across Nostro reference data, SWIFT routing data, release cutoffs, currency mappings and rounding, EBBS accounting data, country time zones, and business-rule lists.

A configuration checklist establishes required values but does not itself demonstrate deployment, maker-checker approval, UAT, reconciliation, or production readiness. Each control domain requires traceable implementation evidence before go-live can be confirmed.

The checklist covers Bahrain, Qatar, Kenya, Zambia, Uganda, Tanzania, Ghana, Nigeria, Sri Lanka, Vietnam, Pakistan, and Bangladesh, including the distinct Sri Lanka FCB record.
