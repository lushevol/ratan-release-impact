# Settlement Accounting

Settlement Accounting is the accounting function affected by the Manual Rounding requirement. The source states that Settlement Accounting should follow the existing process while using the same updated amount as SWIFT.

The specific accounting platform, posting interface, and reconciliation treatment are not identified. Any relationship to [[concepts/ebbs-accounting-configuration]] or [[concepts/ebbs-settlement-posting-configuration]] requires confirmation.
