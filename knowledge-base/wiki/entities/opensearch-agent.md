# OpenSearch Agent

The OpenSearch Agent is the planned component for technical data loading into [[opensearch]]. Its FMRP2 installation is assigned to zhang jiangnan and Zeyu Zhou, and its schema update is described as based on the UBER Open search agent Query service.

The plan contains two dates that may refer to different delivery milestones:

- 2025-12-31: technical go-live to receive.
- 2026-01-31: delivery to production for technical data loading.

The source does not explain the distinction, confirm either milestone as complete, or define the agent's data contract, retry behavior, or operational ownership after release.
