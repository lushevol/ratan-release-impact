# Citibank (USA)

**Citibank (USA)** is used in the source as the host institution for a USD account opened by **Industrial and Commercial Bank of China (ICBC)** for cross-border USD settlement.

From Citibank’s perspective, the account is a [[vostro-account]] because it holds ICBC’s funds. From ICBC’s perspective, it is a [[nostro-account]].

The source provides no further profile of Citibank and does not establish any RATAN integration involving the bank.
