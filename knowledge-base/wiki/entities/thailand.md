# Thailand

Thailand is identified through the `TH` code as part of the 2025 Tranche 1 CPT list for cash-settlement onboarding.

The LMS Feed Entity List Update explicitly includes `TH` in the blacklist. The onboarding checklist also calls for routing, SWIFT generation, currency release time, settlement accounting, branch GUI controls, Vostro and Nostro setup, and business-rule configuration. Final values and completion evidence are not included.
