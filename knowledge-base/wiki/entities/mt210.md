# MT210

MT210 is the SWIFT message generated for an eligible notice-to-receive cashflow.

## Dependency on Ordering-Customer Information

When an SCB Receive cashflow has no stamped vostro, RATAN may select the primary nostro. If `notice to receive = Y`, MT210 generation requires ordering-customer information that may not be available from the primary-nostro instruction.

The requirement introduces SCI-based enrichment to populate the missing information during SSI auto stamping. The acceptance cases expect successful MT210 generation when SCI supplies the required data.

If SCI provides no value or an exception occurs, the requirement expects no auto-population and an MT210 generation error. It does not define whether the error blocks release, creates an SSI exception, or triggers an operational alert.
