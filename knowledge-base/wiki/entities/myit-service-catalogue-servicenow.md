# myIT Service Catalogue / ServiceNow

The myIT Service Catalogue is the documented request channel for RATAN ONE access in the source guide. The specified catalog item is `RATAN ID Creation/Amendment`.

The guide directs requesters to select a group and sub-group, role, and subject before submitting the request. It also states that `X_RATANONE` and `RATAN_DATA_ENTITLEMENT` require bulk-request provisioning while the corresponding E-Form upgrade remains in progress.

The document does not establish whether this workflow or catalog item remains current. See [[what-is-the-current-ratan-one-entitlement-provisioning-and-approval-routing]].
