# MX 2.11

MX 2.11 is the label used in interface 14165 for the recipient of updated cashflow status after [[ratan]] processes settlement cashflows received from [[murex-g2000]].

The source does not establish whether MX 2.11 denotes a Murex software version, system instance, application endpoint, message format, or separate integration target. It should not be assumed to be synonymous with Murex G2000 without corroborating evidence.
