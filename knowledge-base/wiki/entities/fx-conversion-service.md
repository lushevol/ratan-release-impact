# FX Conversion Service

The FX Conversion Service, also called the FX Conversion API in the requirement, is an external dependency used by [[ratan]] to calculate a payment's USD-equivalent value for the [[high-value-payment-exception]].

The source references “FX Conversion Service - Functional Specification” but does not provide its API contract, rate-selection rules, error handling, or availability requirements.
