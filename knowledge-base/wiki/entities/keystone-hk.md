# Keystone (HK)

## Accounting role

Keystone (HK) is the accounting context identified for HK settlement processing. The checklist requires:

- Nostro data to be fed to [[ebbs]].
- Over Account data to be fed to [[ebbs]].
- Suspense data to be fed to [[aspire]].

The source also identifies historic cashflows, past-value cashflow events after cutover, and the transition from Aspire to EBBS as relevant accounting considerations.

## Evidence limitations

No Keystone account identifiers, branch codes, transaction types, event mappings, or reconciliation evidence are provided. The routing model should be validated before onboarding approval.
