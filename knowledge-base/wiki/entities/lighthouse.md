# Lighthouse

## Role in the source

Lighthouse is used to assess RatanOne loading performance through FCP, TTI, TBT, LCP, and a performance score.

The benchmark scores decreased from 27 in Cases I and II to 13 in Case IV as more blotter applications were composed. The source states that the notebook used for testing performed poorly, so the absolute scores are not production-grade measurements.

The source uses the Lighthouse score calculator to illustrate that reducing TTI and TBT could improve the overall score. Relative changes between workspace cases are more informative than the reported absolute scores.
