# TL

`TL` is the system referenced as the source from which an `uber` message can be uniquely identified and retrieved using a trade ID and version.

The source does not expand the acronym or specify a lookup API, authorization model, timeout behavior, unavailable-version handling, or whether the requested version is a major or minor version.
