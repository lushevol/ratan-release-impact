# AI Factory

AI Factory is the named processing layer expected to process client responses to cashflow-affirmation emails and provide a signal that can drive automated settlement in [[ratan]].

The source does not specify its capabilities, input channels, extraction model, classification categories, confidence scoring, correlation logic, human-review process, or output contract. It should therefore not yet be treated as a defined automated settlement authority.

See [[affirmation-response-processing]] and [[what-ai-confidence-and-exception-rules-govern-automated-settlement]].
