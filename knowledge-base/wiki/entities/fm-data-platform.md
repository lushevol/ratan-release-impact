# FM Data Platform

FM Data Platform is the platform on which [[ratan]]'s EOD processing capability is built as a tenant.

The RATAN application profile links this tenancy to risk/valuations feed adoption for Operations systems and to a [[murex-eod-proxy]] solution for migration-related EOD processing.

No deployment topology, tenant-isolation model, data-governance model, operational ownership, or service-level commitment is provided by the source.
