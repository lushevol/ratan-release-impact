# iCDMS

iCDMS is identified in the netting requirement as the system providing the netting agreement document used in cashflow netting eligibility.

The source does not specify the iCDMS interface, document identifier, runtime lookup behavior, or ownership of agreement data. It states only that an iCDMS netting agreement document, together with an SCI netting flag, supports the setup of netting eligibility in [[entities/ratan]].
