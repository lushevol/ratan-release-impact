# FMO_OPS

## Role

`FMO_OPS` is the user profile identified as being used for the legacy BCS flow.

## Migration Relevance

Users operating the migrated flow need to switch from the legacy profile to the profile required by Strategic Workflow. The required target profile, permission set, and provisioning process are not specified in the source.
