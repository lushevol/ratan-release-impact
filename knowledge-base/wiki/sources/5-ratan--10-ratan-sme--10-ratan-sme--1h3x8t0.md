# RATAN SME Reference Links

## Summary

This source is a curated navigation hub for RATAN subject-matter experts. It points to five internal Confluence resources covering release information, miscellaneous RATAN material, pending remediation and security work, recurring production incidents, and key deliverables.

The source is a reference index rather than an evidentiary operational record. It does not provide owners, dates, statuses, metrics, decisions, incident details, remediation items, release outcomes, or delivery commitments.

- [RATAN-MISC](https://confluence.global.standardchartered.com/display/PSS/RATAN-MISC) — miscellaneous RATAN information; scope is not defined in this source.
- [Ratan Pending PID remediations, vulnerabilities, cert renewal](https://confluence.global.standardchartered.com/display/PSS/Ratan+Pending+PID+remediations%2C+vulnerabilities%2C+cert+renewal) — a reference point for pending PID remediation, vulnerability, and certificate-renewal work.

- [Ratan Tracking of List of key deliverables](https://confluence.global.standardchartered.com/display/PSS/Ratan+Tracking+of+List+of+key+deliverables) — a reference point for key-deliverable tracking.

## Evidence boundaries

The existence and titles of the five linked resources are directly supported by this source. Their contents, authority, ownership, update cadence, completeness, and current status are not established. In particular, the source does not identify the meaning of PID, list any vulnerability or certificate, define what qualifies as a repeated incident, or identify any deliverable.

The links broaden the apparent RATAN operating model beyond individual release and CAB records to include operational risk, security maintenance, production reliability, and delivery management. This is an inference from the categories represented by the links, not evidence that the associated processes are effective, integrated, or centrally owned.
