# Data Ops

Data Ops is the operational user profile identified by the 2024 cashflow auto-netting requirement as the only profile permitted to access the Auto Netting Rule Blotter.

The requirement assigns Data Ops the ability to:

- Create auto-netting rules using supported fields.
- Add exclusion criteria.
- Set a business-calendar-relative netting datetime.
- Update and delete rules.

The requirement also assigns Ops responsibility for manually checking cashflows stranded in Pending Auto Netting when a rule is updated or deleted before the scheduled netting datetime. It does not identify a named team owner, escalation path, reconciliation report, or service-level agreement.
