# Is Hard Block Swap Agent Currently Enabled?

The document history for V2.7 says that the `Hard Block Swap Agent` exception and associated manual-netting blocker were deleted. However, the exception table and a dedicated later section still describe the exception as a hard blocker for Swap Agent Coupon and Interim MTM cashflows.

## Risk

Operators could either release a payment that should remain blocked or delay a payment based on stale documentation.

## Required resolution

Confirm the current production behavior for:

- Swap Agent Coupon and Interim MTM cashflows settled as gross.
- Net resultants containing these component payment types.
- The exception code, if any, generated by RATAN.
- Whether the V2.7 deletion was deployed, superseded, or only partially applied.

The answer should identify the controlling release, effective date, and owning team.
