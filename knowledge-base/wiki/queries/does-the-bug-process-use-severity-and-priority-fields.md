# Does the Bug Process Use Severity and Priority Fields?

Although the document is titled as a bug-handling process, its table defines a generic story workflow. `Prioritized` requires a priority value, but no severity, business-impact, reproduction, environment, workaround, or regression fields are described.

## Evidence needed

- The Cash Settlement ADO work-item type definitions for stories and bugs.
- Mandatory-field configuration by work-item type.
- Bug triage guidance, including severity and priority definitions.
- Representative bug records showing the operational process.

This question distinguishes generic workflow evidence in [[story-status-lifecycle]] from a complete defect-management policy.
