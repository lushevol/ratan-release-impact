# Which eBBS Narration Field Mapping Is Authoritative?

The requirement contains an earlier narration mapping and a later table labelled **Apply for ALL**. They differ for `narration4`, `narration5`, `narration6`, and several extended-narrative fields.

The later table may supersede the earlier mapping, but the document does not state an effective date, version, or approval decision. This query should be resolved before treating either mapping as the canonical interface contract.
