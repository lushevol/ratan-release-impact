# Which Manual-Entity Configuration Fields Are Mandatory by Message and Currency?

The checklist labels several SWIFT and settlement-accounting settings as mandatory per entity, but also frames Field 53, Field 58, MT604/MT605 receiver BICs, PM templates, and branch-specific accounting as conditional or requiring user confirmation.

An authoritative onboarding specification should define required fields by message type, currency, settlement method, branch, and PM status, together with the source of each value and approval owner.
