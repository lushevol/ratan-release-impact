# Should Manual Entities Use the UK SSI Stamping Hierarchy?

The checklist describes both an old SSI model and a UK/new model, but does not select the required hierarchy for a newly onboarded manual entity.

The decision should define whether “Country Specific + Global Product” takes priority over “Global Entity + Product Specific,” identify permitted exceptions, and specify migration treatment for entities using old logic.
