# What Is the Authoritative Indonesia Cashflow Classification Rule for Fixing Flags?

The draft says that GDC should publish a message when a cashflow is “identified as an Indonesia cashflow” after querying booking-entity FMID. It does not define the rule.

This decision requires the authoritative FMID source and format, eligibility mapping, ownership of reference data, handling of missing or conflicting FMIDs, and confirmation of whether booking entity alone determines Indonesia eligibility.
