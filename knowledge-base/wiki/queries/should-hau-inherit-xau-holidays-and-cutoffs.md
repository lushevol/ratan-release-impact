# Should HAU Inherit XAU Holidays and Cut-offs?

The source asks separately whether HAU should have dedicated holiday and cut-off static data or inherit existing [[xau]] configuration.

Rounding reuse is explicitly recorded, but that does not approve inheritance for holiday calendars or cut-off times. An approved policy should identify the owner, effective dates, static-data records, exception handling, and validation evidence for each configuration domain.
