# Which Version of the FMRP SWIFT Field Rules Is Authoritative?

## Question

Which amendments supersede the original 2024 field rules, especially the 2025 INR LEI rules and the 2026 precious-metals strategy/static-data changes?

## Evidence

The source is filed as a 2024 functional requirement but contains later changes including ADO#7412111, ADO#9493232, ADO#9971484, and 2026 updates to precious-metals strategy logic.

Some older logic is struck through, while other pseudocode is amended inline without a version history, effective date, approval record, or test traceability.

## Required resolution

A controlled rule catalogue should identify each field rule’s effective date, superseding change, approved owner, implementation version, and regression-test evidence.
