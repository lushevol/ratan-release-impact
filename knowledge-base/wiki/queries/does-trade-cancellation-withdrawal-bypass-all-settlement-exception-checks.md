# Does Trade-Cancellation Withdrawal Bypass All Settlement Exception Checks?

A deprecated Stella event matrix says a withdrawal cashflow resulting from trade cancellation is a special STP case that bypasses SSI checking, NSTP checking, and suppression checking.

Confirm whether this behavior remains implemented, define the precise eligible event types and source populations, and establish required audit, approval, and exception controls. The deprecated statement must not be treated as a universal cashflow-suppression rule.
