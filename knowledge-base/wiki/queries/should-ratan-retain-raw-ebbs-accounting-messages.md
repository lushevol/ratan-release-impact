# Should RATAN Retain Raw eBBS Accounting Messages?

The requirement explicitly asks whether RATAN needs to store raw accounting messages but provides no decision.

Resolution should define retention period, access control, masking, audit usage, replay support, reconciliation requirements, and handling of rejected or superseded messages.
