# What Is the Post-Value-Date Processing Model for Cashflow-Suppressed Cashflows?

The requirement explicitly defines Razor accounting, reversal accounting, and replacement accounting for `SWIFT SUPPRESSED` cashflows. It does not define equivalent treatment for `CASHFLOW SUPPRESSED` cashflows.

Clarification is required for accounting feeds, audit records, trade cancellation, trade amendment, and remediation when a Cashflow-Suppressed cashflow requires processing after value date.
