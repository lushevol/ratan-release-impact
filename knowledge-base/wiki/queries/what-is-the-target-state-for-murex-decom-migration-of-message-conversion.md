# What Is the Target State for Murex Decom Migration of Message Conversion?

The source says that RATAN conversion of inbound SWIFT MT messages and Payment XML to “MX (ISO 20022)” is pending a full decommission migration from Murex, which is expected to centralize the logic.

The target platform, ownership, scope, delivery timeline, interim controls, migration plan, and criteria for retiring existing RATAN conversion logic are not stated.

Resolution should identify the approved target architecture and mapping authority, affected message types, service owner, implementation milestones, parallel-run or reconciliation requirements, and the formal decommission decision.
