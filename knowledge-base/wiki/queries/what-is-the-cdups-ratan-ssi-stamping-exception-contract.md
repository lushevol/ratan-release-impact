# What Is the CDUPS-RATAN SSI Stamping Exception Contract?

The source confirms that exception handling between CDUPS and RATAN is required and that stamped responses may contain exceptions as an extension.

It does not define the exception catalogue, response schema, correlation identifier, retry and timeout rules, resolution ownership, maker-checker interaction, or recovery and reconciliation behavior. These details are required for a production integration.
