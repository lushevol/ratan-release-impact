# How Does LCM Inter-Entity Netting Coexist with the Same SCB Entity Rule?

The shared requirements permit netting only within the same SCB Entity, while the Ratan-only requirements call for inter-entity netting through [[lcm]].

Determine whether LCM is a governed exception, uses an entity boundary distinct from SCB Entity, or represents a conflict requiring requirement revision.
