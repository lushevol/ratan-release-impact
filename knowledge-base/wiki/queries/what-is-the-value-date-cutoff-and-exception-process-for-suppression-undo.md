# What Is the Value-Date Cutoff and Exception Process for Suppression Undo?

The requirement permits un-suppression only until value date and directs post-value-date remediation to Oscar for Cashflow Suppression and AMH / Oscar for Payment Suppression.

It does not define the timezone, business calendar, intraday cutoff, interface validation, authorization, or treatment when an amendment changes value date. The operational ownership split between AMH and Oscar also requires confirmation.
