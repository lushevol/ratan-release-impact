# What Is the Authoritative Payment Lake and CDU Lake Relationship?

The deprecated SFMRP integration document calls the payment lake the store of current cashflow status and versions, queried by Stella and Blade. Existing documentation references [[cdu-lake]], but this source does not identify the two names as the same component.

Determine whether payment lake is an earlier name for CDU Lake, a distinct persistence store, or a logical layer spanning multiple systems. Confirm ownership, query APIs, record identity, version semantics, and migration history before linking or merging the entities.
