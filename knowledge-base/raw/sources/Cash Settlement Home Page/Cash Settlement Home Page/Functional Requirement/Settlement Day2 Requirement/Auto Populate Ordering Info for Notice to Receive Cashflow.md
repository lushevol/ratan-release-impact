# Background

Currently vostro is not mandatory for SCB receipt. If no vostro found for the cashflow, system will pick the primary nostro automatically. But if the notice to receive flag is ticked from the primary nostro, system will try to generate MT210 which requires the ordering customer info from vostro.

This change will automatically populate the ordering customer info for such case to avoid swift generation error

SCB Receive 2. no vostro stamped (missing vostro but no si exception) 3. notice to receive = Y 4. paymentCurrency is not in ("XAU", "XAG", "XPD", "XPT") 5. ~~check if we need to add condition: settlement means = NOS~~, Dinesh will check and confirm
