# CN Vostro :

- How we identify the CN Vostros: - All SSI with CN entities on the field '**Branch ID**' - '**Branch ID**' =='**Global**' and '**Trading Account**' is CN related clients.

- SSI entitiy '**Global'**(2108) VS '**Beijing/Shanghai/other entities**'(3526): - If brnach id is defined as 'Global' means this SSI is applicable for all SCB branches - If branch is is defiend as 'Beijing'/'Shanghai' means it's only applicalbe for the particular entity.
- SSI+ Security '**MXG Blank**'(3906) VS '**MXG XXX**'(1728) : - If the SSI security is defined as '**MXG Blank**' means this SSI is applicable for all murex products - If the SSI security is defined as 'MXG XXX' like 'MXG IRS' it would be applicable for the particular murex products only.
- Global + MXG Blank: There're 1536 SSI defined for all entities & all Murex products.
