# Background:

As requested by FMO the trade affirmation/confirmation status is one of the key factors to drive the cashflow STP, Ratan need to consume the trade confirmation status from CDU and identify the underlying cashflows.

When received the trade confirmation status notification message from CDU,  Ratan will expect there're sufficient identifiers in this  message  and help to search the corresponding cashflow in Ratan.

# Candidate identifiers to link the trade & cashflow:

- Trade ID: - Logical Model Path: Trade.Trade_Id - SCBML Path: (/scb:SCBML/scb:payload/scb:FPMLPayload/conf:trade|/scb:SCBML/scb:payload/scb:FPMLPayload/*/(*:originalTrade|*:trade))/conf:tradeHeader/conf:partyTradeIdentifier[conf:partyReference/@href="party1"]/conf:tradeId[@tradeIdScheme="[http://www.sc.com/coding-scheme/tradeId](http://www.sc.com/coding-scheme/tradeId)"]
- Tracking Version: - Logical Model Path: Trade.Tracking_Version partyTradeIdentifier - SCBML Path: /scb:SCBML/scb:payload/scb:FPMLPayload/scb:header/scb:process/scb:trackingVersion
- Event ID: - Logical Model Path: Trade_Event.Event_Id - SCBML Path: /scb:SCBML/scb:payload/scb:FPMLPayload/scb:header/scb:process/scb:eventId[@eventIdScheme="[http://www.sc.com/coding-scheme/eventId](http://www.sc.com/coding-scheme/eventId)"]
