# Background

The trade affirmation/confirmation status is one of the key attributes to drive the cashflow STP/NSTP.

# Murex 2.11 Trades & Cashflows

BAU flow between Murex 2.11 & CDU

- Trade message flow : Murex 2.11 ->MQ→ MLS → EDMI → CDU Exceptor
- Confirmation status reversal flow: CDU Exceptor →EDMI →MLS → MQ→ Murex 2.11

# Stella trades & Cashflows

- Trade message flow: Stella/TDS3->Solace→ CDU PS
- confirmation status notification flow : CDU PS → Stella → TDS3 → Ratan

# CDU Lake

CDU Lake is consolidating the confirmations status for different TP systems.

- Murex 2.11 trades - Paper ( sourcing from CDU Exceptor)
- Murex 2.11 trades - Swift ( sourcing from CitiNet)
- Stella 2.11 trades - Paper/Swift( sourcing from CDU PS) - FMRP

# CDU Lake → Ratan Confirmation notification

Ratan will consume the trade confirmation status from CDU Lake for both Murex 2.11 & Stella trades, the message would be sent through different Solace topic. CDU lake is segregating the trade topics by different source system & product asset class.
