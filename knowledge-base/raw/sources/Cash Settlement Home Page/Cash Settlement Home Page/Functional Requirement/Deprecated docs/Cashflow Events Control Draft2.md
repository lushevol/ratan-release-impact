# Background

There'll be multi events populated on cashflows by Stella which are driven by the trade market event.

- New: New cashflow generated by trade lifecycle event like new trade booking/observation events( e.g. fixing)
- Withdrawal: Driven by the trade market event which need to cancel the cashflow.
- Amendment: Driven by the trade market event which there's update on the amount, currency, date, counterparty, booking entity, payment type and settlement method. This cashflow event is applicable when the trade market event happen before the cashflow 'Netted'/'Released'/'Settled'.
- Withdrawal & New: Similar with cashflow 'Amendment' but 'Withdrawal & New' is populated when the trade market event happen on the 'Netted'/'Released'/'Settled' cashflows.
