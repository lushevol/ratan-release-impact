| --- | --- | --- | --- |

# Swift field 20 generation logic

- The maxim length of swift field 20 is 16.
- For BCS the field 20 name conversion it's 'EQ02003791883175' - EQ is the hardcode prefix which stands for Equity - '02' is the branch code of booking entity - 00379188317 is the cashflow id generated by FMRP Stella, with maxim length as 12.
- Field 20 can be combination of alphabet and numeric.

# Ratan cashflow id generation logic

- Need to populate new cashflow id for netting/split cashflow
- Cashflow id must be unique across Ratan services/process
- Netting resultant cashflow id name conversion is 'N' + 11 numeric value - 'N' stands for 'Netting' - 11 length numeric id starting from 00000000001 - 11 length numeric id is auto increased
- Split cashflow id name conversion is 'S' + 11 numeric value - 'S' stands for 'Split' - 11 length numeric id starting from 00000000001 - 11 length numeric id is auto increased

# Ratan cashflow id generation API

- Request parameter ```js { Request_Service: "Manual netting"/"Auto Netting"/"Manual Split"/"Auto Split" CashflowId_Type: "Netting" or "Split" } ```
- If the CashflowId_Type is 'Netting' then the cashflow prefix is 'N', otherwise is 'S'
- Concurrency should be considered if multi process requesting the cashflow id generation
