- **Multi Payments**: <scb:payment> is the child node of <scb:cashflow>, the major payment economic information will be captured under the tag <scb:payment> like Currency/Value Date/Amount. Normally there would be one payment tag under the <scb:cashflow> tag, but there'll case multi <scb:payment> tag presenting under the <scb:cashflow>. But only one <scb:payment> would be handled by settlement platform while can igonore others which are just for query & display purpose for Blade(normally for XVA payments). The way we diffrenciate the to be settled payment vs the payments just for information. a) <scb:isIntentToSettle>true</scb:isIntentToSettle> : Only the to be settled payment would be tagged as 'true' on this atrribute. b) <scb:isIntentToSettle>false</scb:isIntentToSettle>: All the other payments would be tagged as 'false'.

Business Rule:

If payment_Count>1

        If payment_Count with intendToSettle = True >1 or =0

        Then pick the 1st Payment

        Else If payment_Count with intendToSettle = True = 1

        Then remove payment with intendToSettle = False
Else Skip this check
