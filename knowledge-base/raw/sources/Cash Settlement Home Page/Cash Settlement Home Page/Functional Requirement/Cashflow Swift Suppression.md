# Background:

There'll be 2 types of suppression in Ratan STP workflow, STP flow can be found in [https://confluence.global.standardchartered.com/display/DSP/Function+Flow](https://confluence.global.standardchartered.com/display/DSP/Function+Flow)

- Cashflow Suppression: 1. To be used for scenarios where **<u>payment and settlement accounting is not required</u>** 2. Cashflow Suppress Rules Table will be used to auto suppress Cashflows 3. If a client was incorrectly added to Cashflow suppression table, it has to be removed from Cashflow suppression table to resolve that 4. Users can manually suppress a cashflow with Maker / Checker 5. If Cashflow suppression was done in error, Un-suppression can be done until Value date. 6. Un-suppression cannot be done beyond value date. If payment + accounting is required, it has to be handled via Oscar 7. If there is any amendment / cancellation on the trade, then it will be handled as a new version by system and go through new lifecycle.
- Payment Suppression: 1. To be used for scenarios where we know that **<u>payment is not required</u>** 2. Payment Suppress Rules Table will be created to auto suppress for scenarios where every single cashflow will be payment suppressed (clearing deals as an example) 3. If a client was incorrectly added to Payment suppression table, it has to be removed from Payment suppression table to resolve that 4. Manual suppression will go through Maker-Checker 5. If suppression was done in error, Un-suppression can be done until Value date. 6. Un-suppression cannot be done beyond value date. If payment required, it has to be handled via AMH / Oscar 7. If there is any amendment / cancellation on the trade, then it will be handled as a new version by system and go through new lifecycle.

# Post 'Swift Suppression' Flow

# 'SWIFT SUPPRESED' Accounting Requirement:

- On Value Date: By EOD Ratan need to send the cashflow with status 'SWIFT SUPPRESSED', Razor will bypass the swift generation and only run accounting with the status 'SWIFT SUPPRESSED'.
- Post VD Accounting EOD: 1. Cashflow Cancellation: Ratan send cashflow to Razor for reversal accounting entry generation. 2. Cashflow Amendment: Ratan send cashflow to Razor for reversal&new accounting entry generation.
