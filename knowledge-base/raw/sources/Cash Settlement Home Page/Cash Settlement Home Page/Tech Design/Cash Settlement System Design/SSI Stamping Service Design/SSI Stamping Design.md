## Requirement

- Cashflow status is in 'READY' status and user wants to right click and select 'Adhoc SI' to perform SI input
- There's no SSI exception but Maker initiate the 'Adhoc SSI' process, exception generate if Maker's submit succesfully. sub status moved to 'Pending Verificcation'
- There's no SSI exception and Checker reject the SSI, exception generated and sub status updated as 'Pending Operator'
