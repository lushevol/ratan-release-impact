Logic flow

1. Life Cycle monitor topic Trade_Service__Trade_Events
2. check whether the event is MATCHED, and whether the EG Confirmation Status of event message is Confirm or Affirm.
3. check whether the trade is CN Settlement query cashflow data by tradeId and tradeVersion from ratan_stella_message_event_source
4. check whether the cashflow status is WAITING and the action is isNstp.
5. then call interface RATAN-CASH-SETTLEMENT-ORCHESTRATION/v1/camunda/task/mutiException/syncSummary to close exceptions, sync summary of exceptions and update cashflow status.
