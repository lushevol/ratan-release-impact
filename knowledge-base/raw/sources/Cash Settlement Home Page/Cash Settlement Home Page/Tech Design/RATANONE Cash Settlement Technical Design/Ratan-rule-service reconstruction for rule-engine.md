## **Rules validation**

*All type rules will call domain service first. Then domain service generate json from scbml, and pass the json to ratanone-rule-service. At last ratanone-rule-service will response filtered or success. For special rules, it will process some flows and put the result into json, then pass them to ratanone-rule-service together.*
